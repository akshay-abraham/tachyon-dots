# windows/

Not Fedora/Arch — kept here because it's still part of the personal config set, for whichever Windows install (VM or otherwise) this applies to.

`windhawk-taskbar-styler/win_taskbar_mode.cpp` is a custom theme snippet for the [Windhawk](https://windhawk.net/) **Taskbar Styler** mod, used to make the Windows 11 taskbar behave more like a floating dock (centered, blurred background, reduced margins) rather than the default full-width bar.

To use it: install Windhawk, install the Taskbar Styler mod from its store, and paste this file's contents into the mod's custom theme/style field.
